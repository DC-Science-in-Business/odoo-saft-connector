SAF-T Analyser

Upload Portuguese SAF-T XML files in Odoo and get executive KPIs with a premium HTML report — without leaving Odoo.

What it does

  • Upload SAF-T XML files directly from Odoo — no external steps required.
  • Executive KPIs calculated instantly by the D&C analysis engine.
  • Premium HTML management report saved as an Odoo attachment.
  • Full history of analyses per company, accessible any time.
  • Configure the API once in Settings — any user can then run analyses.

KPIs included

Total Revenue (€) Average Ticket (€) Estimated VAT (€) Return Rate (%) Customer Concentration (%) Top Revenue Product Top Revenue Customer

How to use

  1. Configure in Settings: Settings → SAF-T Analyser → fill in API URL, Tenant ID and API Key. Click "Test Connection".
  2. Export your SAF-T: export the XML from your accounting software (PHC, Sage, Primavera, Moloni, Jasmin, etc.).
  3. New Analysis: Accounting → SAF-T Analyses → New Analysis → upload the XML.
  4. View results: KPIs appear on the record. Click "Open HTML Report" for the full report.
