Como funciona

  1. Configure a API em Definições Vá a Definições → SAF-T Analyser. Introduza a URL da API, o Tenant ID e a API Key fornecidos pela D&C. Clique "Testar Ligação" para confirmar.
  2. Exporte o SAF-T do vosso software de contabilidade Qualquer ficheiro SAF-T XML válido (PHC, Sage, Primavera, Moloni, Jasmin, etc.) é compatível.
  3. Clique em "Nova Análise" No menu Contabilidade → Análises SAF-T → Nova Análise. Carregue o ficheiro XML e seleccione o tier (opcional).
  4. Consulte os KPIs e abra o relatório Em segundos, o registo é criado com todos os KPIs visíveis. O botão "Abrir Relatório HTML" abre o relatório detalhado num separador.

Privacidade e segurança

O motor de análise SAF-T corre exclusivamente nos servidores D&C em ambiente seguro. Nenhuma cópia do ficheiro XML original é armazenada — apenas os KPIs calculados e o relatório HTML resultante são devolvidos ao Odoo. A comunicação é feita via HTTPS com autenticação por Tenant ID + API Key.
